## 📌 Tentang Saya

Saya adalah **Backend Engineer dan System Architect** yang fokus membangun sistem backend yang scalable, andal, dan mudah dikembangkan. Pengalaman saya mencakup perancangan REST API, sistem bot otomatis, hingga layanan real-time berbasis WebSocket.

Saya percaya bahwa arsitektur yang baik dimulai dari kejelasan alur data, pemisahan tanggung jawab antar modul, dan kemudahan observasi saat sistem berjalan di production.

## 🏗️ Arsitektur Sistem

```
Client ──► API Gateway (Express) ──► Service Layer ──► MongoDB
                  │                        │
                  ▼                        ▼
            WebSocket Server          Redis Cache
                  │
                  ▼
            Bot Automation
```

- **Client** berinteraksi lewat REST API atau koneksi WebSocket.
- **Express** menangani routing, middleware, dan autentikasi.
- **Service Layer** memisahkan logika bisnis dari transport layer.
- **Redis** menyimpan cache dan state sementara untuk mengurangi beban database.
- **MongoDB** menyimpan data utama dengan skema yang fleksibel.
- **Bot Automation** berjalan sebagai worker yang memproses event dan tugas terjadwal.
